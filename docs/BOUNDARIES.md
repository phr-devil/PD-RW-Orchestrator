# Scientific and operational boundaries

- **Already owned:** PD-RW owns H-stage rules, author decisions, SEALED/VAL/CONFIRMATION policy, manuscript authorization. PD-RW-Agent owns bounded read-only checks and case retrieval. The original project owns scientific evidence.
- **This repo cannot enforce host isolation.** It deliberately fails closed on any `required_effects` with `BLOCKED_AUTH` until a real host bridge is built. Policy documents and result claims cannot grant permissions.
- **Source refs are locators, not authenticity proofs.** Verify project root and original artifacts using the established tools and host.
- **No new scientific records:** task receipts are operational only; do not replicate Run metadata, scientific results or project state.
- **No unauthorized publishing or external requests:** avoid copying real case libraries, unpublished figures, credentials, and local paths into this public repo.
- **No fake validation:** integration/contract tests prove only code behavior. Real multi-Agent and research improvement are NOT_MEASURED.
- **No hidden retries:** uncertain jobs stop for reconciliation; do not rerun training merely due to a missing response.
- **Independent review is not agent voting:** compare original protocol, measurements and claims; unresolved contradictions remain unresolved.
