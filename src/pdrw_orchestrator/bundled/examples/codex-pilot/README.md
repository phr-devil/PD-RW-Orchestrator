# Synthetic read-only Agent pilot

This directory contains **invented toy sensor readings** and intentionally weak
evaluation logic. It is **not** a real dataset, original project, or scientific Run.
The purpose is to assess whether an installed Codex CLI can read this small
fixture and return structured review observations. Never use this fixture to
support a publication claim.

The experimental numbers and labels are artificial. The example includes
temporally adjacent samples in random train/test splits, a potential source
of optimistic evaluation. There may also be other legitimate limitations;
a Codex self-report does not certify their scientific importance.
